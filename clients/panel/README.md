# 面板

面板是**服务端内置**的，不单独发布前端工程：

```bash
slowtrans serve --host 127.0.0.1 --port 8790
# 浏览器打开 http://127.0.0.1:8790/
```

页面源码在 `src/slowtrans/api/panel.html`，单文件、无构建、无 CDN 依赖。
它只调用 `/api/v1/*`，所以面板能做的事，插件和脚本都能做。

## 远程访问

服务只监听回环。从另一台机器看，用 SSH 隧道：

```bash
ssh -N -L 8790:127.0.0.1:8790 aliyun
# 然后打开 http://127.0.0.1:8790/
```

Windows 上封装好的双击脚本在运维仓库：`scripts/slowtrans/open-slowtrans-panel.bat`
（本地 18790 → 服务器 8790）。

## 面板能做什么

- 任务列表、进度、状态
- 章节完成情况、待复核段落（含失败原因）
- 术语表查看与编辑（保存后只影响后续翻译）
- 暂停 / 继续 / 下载成品
- 实时事件流（SSE，断线自动续）

## 它故意不做的事

- 不做富文本编辑、不做任务提交表单：提交走 CLI 或 AstrBot 命令，
  因为服务器上的文件路径需要人工确认。
- 不做鉴权页面：token 直接从浏览器 localStorage 带在 `Authorization` 头里。
  面板本身不保存任何凭据到服务器。
